## 🔧 TROUBLESHOOTING

### Error: "Database Connection Failed"
**Solution:** Ensure PostgreSQL is running. Check connection string in `.env` file. Verify database exists and migrations are applied.

### Error: "Port 3000 Already in Use"
**Solution:** Kill existing process using `netstat -ano | findstr :3000` and `taskkill /PID <PID> /F`. Or change port in config file.

### Error: "Upload Failed - File Too Large"
**Solution:** Increase upload limit in backend config. Check cloud storage quota. Compress images before uploading.

### Error: "Socket Connection Refused"
**Solution:** Verify WebSocket server is running on correct port. Check firewall rules. Enable Socket.io debug mode for detailed logs.

### Error: "JWT Token Invalid"
**Solution:** Clear browser cookies and localStorage. Re-login to generate new token. Verify JWT_SECRET in environment variables matches.
